<h1>Qiskit 2.x Practice Exams</h1>

I will be creating some practice exams here. Instead of the usual approach to create different questions which cover each of the subjects in the syllabus, I will create sets of questions which cover just a small subset. 
The idea is having the opportunity to practice a concept multiple times and getting confident on that section. For example, questions only focused on rotations, visualizations, the REST API ...

- [Qubit Rotations](./Practice/rotations.md) 👷‍♂️
  Understanding how different rotations affect the probability of finding a |0> or |1> state.
- [Pauli](./Practice/pauli.md) 👷‍♂️
  Different type of operations involving Pauli gates (including both Pauli and SparsePauliOp classes). Also equivalenies between different sequences of Pauli gates.
- Visualizations 👷‍♂️
  Understanding the different types of visualizations: being able to identify bell states in different types of visualizations, etc.
- [REST API](./Practice/rest.md) 👷‍♂️
- Circuits 👷‍♂️
  This includes the use of gates, drawing circuits (different options), using feedforward/loops in both syntaxes.
