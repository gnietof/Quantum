# Qiskit 2.x Practice Exams

I will be creating some practice exams here. Instead of the usual approach to create different questions which cover each of the subjects in the syllabus, I will create sets of questions which cover just a small subset. 
The idea is having the opportunity to practice a concept multiple times and getting confident on that section. For example, questions only focused on rotations, visualizations, the REST API ...
